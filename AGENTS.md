# Project Instructions

1. Use UV for Python package management.
2. If the project uses Python, always create/use a UV virtual environment. If `.venv` is not already instantiated, create it with UV before running Python project commands.
3. UI fields must be self-explanatory. Do not ship bare inputs that rely only on placeholders or stored values. Use visible labels, sensible examples, and short helper text where the user may not know the required format or business meaning.
4. Avoid disruptive overlay UI for routine data-entry workflows. Prefer inline controls, table actions, or clearly scoped edit forms that do not cover the data the user is working with.
5. Invoice numbering is property-specific and belongs in the Owners/property management area, not global Settings.
